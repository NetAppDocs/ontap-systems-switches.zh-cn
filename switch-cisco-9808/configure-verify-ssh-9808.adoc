= 验证 Cisco Nexus 9808 交换机上用于日志收集的 SSH
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
确认已在 Cisco Nexus 9808 交换机上启用 SSH，以支持以太网交换机运行状况监视器 (CSHM) 和日志收集功能。

.开始之前
您必须使用串口控制台连接到交换机。

.步骤
. 确认 SSH 已启用：
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. 请确认 SSH 密钥已启用：
+
`show ssh key`

.下一步是什么？
* 在验证SSH已启用日志收集后，即可 link:../switch-cshm/cshm-overview.html["配置以太网交换机运行状况监控"]。
* 配置以太网交换机运行状况监控后，如果您想利用 Cisco 的 Smart Call Home 支持功能，您link:configure-smart-call-9808.html["配置 Smart Call Home"]。
