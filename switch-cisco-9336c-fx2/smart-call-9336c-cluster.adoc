= 智能呼叫中心的要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要使用 Smart Call Home，您必须配置集群网络交换机以通过电子邮件与 Smart Call Home 系统进行通信。此外，您还可以选择设置集群网络交换机，以利用 Cisco 的嵌入式 Smart Call Home 支持功能。

Cisco 的 Smart Call Home 可监控网络上的硬件和软件组件。当发生关键系统配置时，它会生成基于电子邮件的通知，并向目标配置文件中配置的所有收件人发出警报。

[NOTE]
====
ONTAP 支持以太网交换机健康监控 (CSHM) 来监控 AFX 集群交换机，以及收集交换机诊断日志的功能。

Cisco 的 Smart Call Home 可以提供主动支持，并帮助您解决交换机可能出现的任何问题。

====
在使用 Smart Call Home 之前，请注意以下要求：

* 必须架设邮件服务器。
* 交换机必须与邮件服务器建立IP连接。
* 必须配置联系人姓名（SNMP 服务器联系人）、电话号码和街道地址信息。这是为了确定所接收消息的来源。
* CCO ID 必须与贵公司适用的Cisco SMARTnet 服务合同关联。
* 设备必须安装Cisco SMARTnet 服务才能注册。


这 http://www.cisco.com/c/en/us/products/switches/index.html["Cisco支持网站"^]包含有关配置智能呼叫中心命令的信息。

可以在新系统安装和设置期间或之后配置 Smart Call Home。
