= 了解以太网交换机运行状况监控
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
以太网交换机运行状况监视器（CSHM）主动监控 ONTAP 中集群和存储网络交换机的运行状况，对检测到的故障发出警报，并收集交换机日志以供调试。

CSHM 监控集群和存储网络交换机，以维护网络基础设施的可靠性。运行状况监视器会自动检测交换机问题，收集日志以进行故障排除，并在出现网络问题时提供警报。CSHM 支持多个交换机供应商和型号，帮助您在网络连接问题影响存储环境之前识别并解决这些问题。
