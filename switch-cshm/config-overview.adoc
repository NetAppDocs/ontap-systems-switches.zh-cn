= 了解如何配置以太网交换机运行状况监控
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
以太网交换机健康监视器（CSHM）负责确保网络交换机的运行健康，并收集交换机日志以进行调试。

在使用 CSHM 监控网络交换机之前，必须配置日志收集，并可选择配置 SNMPv3 以增强安全性。CSHM 需要日志收集来收集交换机日志和诊断数据。SNMPv3 提供 ONTAP 与交换机之间的安全通信。

* link:config-log-collection.html["配置日志收集"]
* link:config-snmpv3.html["配置 SNMPv3（可选）"]
