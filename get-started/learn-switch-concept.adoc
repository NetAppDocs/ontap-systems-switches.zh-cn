= 了解 ONTAP 系统交换机
:allow-uri-read: 


[role="lead"]
ONTAP 提供 AFX 系统、集群、存储和共享交换机，可提供内部通信，并能够在集群中无中断地移动数据和网络接口。

“前端”交换机提供与主机存储的连接，而“后端”集群交换机提供两个或多个NetApp控制器之间的连接。


NOTE: 仅支持经NetApp验证的后端交换机（从NetApp订购）。


CAUTION: 如果要升级交换机，NetApp 建议您首先完成任何 ONTAP 软件升级，然后对交换机执行软件升级。



[[afx-systems-switches]]
== AFX 系统交换机

AFX 系统交换机允许您创建快速、节能和节省空间的网络交换机。它们的小尺寸和高端口密度使其成为处理大型网络的理想选择。端口支持不同的速度，可以拆分为多个连接。NetApp 支持的 AFX 系统交换机包括：

* Cisco Nexus 9808
* CiscoNexus 9332D-GX2B
* CiscoNexus 9364D-GX2A




[[cluster-switches]]
== 集群交换机

集群交换机允许您构建具有两个以上节点的ONTAP集群。NetApp支持的集群交换机包括：

* 博通 BES-53248
* CiscoNexus 9336C-FX2




[[storage-switches]]
== 存储交换机

存储交换机允许您在存储区域网络 (SAN) 中的服务器和存储阵列之间路由数据。  NetApp支持的存储交换机包括：

* CiscoNexus 9336C-FX2




[[shared-switches]]
== 共享交换机

共享交换机允许您将集群和存储功能合并到共享交换机配置中，支持使用共享集群和存储 RCF。  NetApp支持的共享交换机是：

* CiscoNexus 9336C-FX2
