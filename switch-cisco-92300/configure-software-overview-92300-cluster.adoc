= Cisco Nexus 92300YC 集群交换机的软件安装工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要为 Cisco Nexus 92300YC 交换机安装和配置软件，并安装或升级参考配置文件 (RCF)，请执行以下步骤：

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"]link:configure-install-initial.html["配置交换机"]
[role="quick-margin-para"]
配置 92300YC 集群交换机。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"]link:install-nxos-overview.html["准备安装 NX-OS 软件和 RCF"]
[role="quick-margin-para"]
必须在 Cisco 92300YC 集群交换机上安装 Cisco NX-OS 软件和参考配置文件 (RCF)。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:install-nxos-software.html["安装或升级 NX-OS 软件"]
[role="quick-margin-para"]
在 Cisco 392300YC 集群交换机上下载并安装或升级 NX-OS 软件。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四个"]link:install-the-rcf-file.html["安装 RCF"]
[role="quick-margin-para"]
首次设置 Cisco 92300YC 交换机后，安装 RCF。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"]link:configure-ssh-keys.html["验证 SSH 配置"]
[role="quick-margin-para"]
验证是否已在交换机上启用 SSH 以使用以太网交换机运行状况监视器 (CSHM) 和日志收集功能。
