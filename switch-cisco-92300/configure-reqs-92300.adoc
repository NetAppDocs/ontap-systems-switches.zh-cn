= 查看 Cisco Nexus 92300YC 集群交换机的配置要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在安装或升级之前，请查看 Cisco Nexus 92300YC 集群交换机的配置要求。

如果要构建包含两个以上节点的ONTAP集群，则需要两个受支持的集群网络交换机。您还可以使用额外的管理交换机，这些交换机是可选的。



[[configuration-requirements]]
== 配置要求

要配置集群，需要为交换机提供适当数量和类型的电缆和电缆连接器。根据最初配置的交换机类型，需要使用随附的控制台电缆连接到交换机控制台端口；还需要提供特定的网络信息。



[[network-requirements]]
== 网络要求

所有交换机配置均需要以下网络信息：

* 管理网络流量的 IP 子网
* 每个存储系统控制器和所有适用交换机的主机名和 IP 地址
* 大多数存储系统控制器可通过连接到以太网服务端口（扳手图标）的 e0M 接口进行管理。在 AFF A800 和 AFF A700 系统上，e0M 接口使用专用以太网端口。


.相关信息
