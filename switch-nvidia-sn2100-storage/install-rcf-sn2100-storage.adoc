= 在 NVIDIA SN2100 存储交换机上安装 RCF 脚本
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 NVIDIA SN2100 存储交换机上安装参考配置文件（RCF）脚本，以配置端口分配和网络设置。

.开始之前
在安装 RCF 脚本之前，请确保交换机上具备以下条件：

* 已安装受支持的 Cumulus Linux 版本。
* 通过 DHCP 定义或手动配置的管理端口 IP 地址、子网掩码和默认网关。


.RCF 脚本版本
根据您当前的 ONTAP 和 Cumulus Linux 版本选择适当的存储 RCF 脚本版本。从 https://mysupport.netapp.com/site/info/nvidia-cluster-switch["NVIDIA SN2100 软件下载"^]页面下载 RCF。

.关于示例
以下示例过程显示了如何为存储交换机下载和应用 RCF 脚本。
