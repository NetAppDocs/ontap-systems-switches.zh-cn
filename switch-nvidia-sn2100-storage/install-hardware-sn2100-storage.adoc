= 为 NVIDIA SN2100 存储交换机安装硬件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
按照 NVIDIA 的文档安装 NVIDIA SN2100 存储交换机硬件。硬件安装是配置交换机进行存储网络操作之前的第一步。

按照下面的步骤设置和配置 SN2100 交换机。有关详细说明，请参阅 NVIDIA 的文档。

.步骤
. 复习link:configure-reqs-sn2100-storage.html["配置要求"]。
. 按照 link:https://networking-docs.nvidia.com/sn2000hw/latest/installation["NVIDIA开关安装指南"^] 中的说明操作。


.下一步是什么？
硬件安装完毕后，您可以……link:cabling-considerations-sn2100-storage.html["检查布线和配置"]要求。
