= 为 NVIDIA SN2100 存储交换机连接 NS224 驱动器架的缆线
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当直连存储不适用于您的配置时，使用 NVIDIA SN2100 存储交换机将 NS224 驱动器架连接为交换机连接存储。

* NS224 电缆驱动货架通过存储交换机：
+
https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580["NS224 驱动器机架的布线交换机连接信息"^]

* 安装存储交换机：
+
https://docs.netapp.com/us-en/ontap-systems-switches/index.html["AFF和FAS交换机文档"^]

* 确认您的平台型号支持的硬件，例如存储开关和电缆。有关详细信息，请参见 link:https://hwu.netapp.com/["Hardware Universe"^]。
