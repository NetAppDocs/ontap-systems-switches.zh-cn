= 查看布线和配置要求 - Cisco Nexus 9332D-GX2B
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果要在新的 AFX 1K 或 AFX 2K 系统安装过程中安装 Cisco Nexus 9332D-GX2B 交换机、更换交换机或将交换机重置为出厂默认设置，则必须查看以下布线和配置要求。



[[hard-code-the-speed-on-breakout-ports]]
== 对分支端口上的速度进行硬编码

必须对 100GbE 的交换机分支（4x100GbE）端口进行硬编码。如果不对速度进行硬编码，则端口将不会启动，并且将处于错误禁用状态。

例如，要在分支端口 1-14 上硬编码 100GbE，请在配置模式下执行以下操作。示例显示了应用于第一个交换机（cs1）的命令。对第二个交换机重复这些命令。

[listing, subs="+quotes"]
----
(cs1)(config)# *interface e1/1/1-4, e1/2/1-4, e1/3/1-4, e1/4/1-4, e1/5/1-4, e1/6/1-4, e1/7/1-4, e1/8/1-4, e1/9/1-4, e1/10/1-4, e1/11/1-4, e1/12/1-4, e1/13/1-4, e1/14/1-4*
(cs1)(config-if)# *speed 100000*
(cs1)(config-if)# *no negotiate auto*
(cs1)(config-if)# *exit*
(cs1)(config)# *exit*
(cs1)# *copy running-config startup-config*
----
.下一步是什么？
在满足布线和配置要求后，您 link:configure-install-nxos-9332d.html["安装 NX-OS"]。
