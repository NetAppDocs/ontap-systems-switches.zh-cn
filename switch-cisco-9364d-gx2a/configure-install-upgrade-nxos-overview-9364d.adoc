= 安装或升级 NX-OS 概述 - Cisco Nexus 9364D-GX2A
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Nexus 9364D-GX2A 交换机上为 AFX 1K 和 AFX 2K 系统安装或升级 NX-OS。


NOTE: NX-OS 安装或升级独立于 RCF 安装或升级。如果您要安装或升级 NX-OS 和 RCF，建议您先安装或升级 NX-OS。

* link:configure-install-nxos-9364d.html["安装 NX-OS"]
+
您可以在新的 AFX 1K 或 AFX 2K 系统安装、交换机更换或交换机重置为出厂默认设置的过程中，在交换机上安装 NX-OS。

* link:configure-upgrade-nxos-9364d.html["升级 NX-OS"]
+
您可以升级交换机上的 NX-OS，以支持 AFX 1K 或 AFX 2K 系统上的新硬件或新 ONTAP 版本。
