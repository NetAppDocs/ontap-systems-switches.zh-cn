= 验证用于日志收集的 SSH - Cisco Nexus 9364D-GX2A
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果要将交换机配置为新的 AFX 1K 或 AFX 2K 系统安装、交换机更换或重置为出厂默认设置的一部分，以使用以太网交换机运行状况监视器 (CSHM) 日志收集功能，则必须验证是否在交换机上启用了 SSH。

.开始之前
您必须使用串口控制台连接到交换机。

.步骤
. 确认 SSH 已启用：
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. 请确认 SSH 密钥已启用：
+
`show ssh key`

+

.下一步是什么？
* 在验证SSH已启用日志收集后，即可 link:../switch-cshm/cshm-overview.html["配置以太网交换机运行状况监控"]。
+
** 配置以太网交换机运行状况监控后，如果您想利用 Cisco 的 Smart Call Home 支持功能，您link:configure-smart-call-9364d.html["配置 Smart Call Home"]。


* 如果您将交换机配置为新的 AFX 1K 或 AFX 2K 系统安装的一部分，则必须 link:install-complete-afx-setup-9364d.html["完成 AFX 系统设置"]。
