= 完成 Cisco Nexus 3132Q-V 布线工作表
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
完成 Cisco Nexus 3132Q-V 集群交换机的布线工作表，以记录端口连接和支持的平台配置。

示例布线工作表提供了从交换机到控制器的推荐端口分配示例。空白工作表提供了一个模板，您可以在设置集群时使用该模板。

每个交换机可以配置为单个 40GbE 端口或 4 x 10GbE 端口。
